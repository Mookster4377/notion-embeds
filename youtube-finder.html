    Find videos automatically

    This uses Google's official YouTube search with your own free API key. It picks the top result for each song without a video yet and keeps two runner-ups you can switch to.

    1. Go to Google Cloud: YouTube Data API v3 and click Enable (make a project if asked).
    2. Open Credentials → Create credentials → API key, and paste it here.

    Google allows about 100 searches a day on a free key, so a big playlist takes a few days. Run it again tomorrow and it carries on where it stopped. The key is kept only in this browser.

    Save and load

    Your checkmarks and videos are kept in this browser. Save a backup file now and then, or use it to move your progress to another computer.

    Got a newer song list? Export the Music to Listen To database from Notion as CSV and load it here. Your checkmarks and videos stay with each song.
